# Còpia de referència del configurador web

`original/` és una còpia exacta del configurador de www.modulardom.com/presupuesto (versió v3 rebuda el
17/11/2026: `index.html`, `assets/app.js`, `assets/config.js`, `assets/i18n.js`, `assets/jspdf.umd.min.js`),
sense imatges. Les proves `tests/e2e/test_web_vs_crm.py` l'obren en un navegador i comparen el resultat de
la pantalla amb el motor del CRM per a moltes configuracions.

No es publica: només serveix per verificar que CRM i web calculen igual.
